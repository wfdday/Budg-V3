# Budg V3 — Личный бюджет

Современное прогрессивное веб-приложение (PWA) для учёта финансов.

## Фичи
- Учёт доходов и расходов
- Планирование платежей (аванс / зарплата)
- Авто-расчёт по календарю РФ
- Кредиты с прогнозом
- Темы, оффлайн, PWA
- Экспорт/импорт данных

## Как запустить
```bash
npm install
npm run dev
